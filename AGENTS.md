# Architecture rules
- Security page and downloadable white paper use src/content/security.json as their shared source to prevent conflicting security claims; document observed limitations rather than implying independent certification.
- Desktop downloads use a public view in the existing app router; unavailable packages and store listings stay disabled until real release URLs exist, to avoid misleading downloads.
- Legacy migration reset uses a controlled in-app confirmation dialog, never native browser prompts, so confirmation works in previews and installed apps.
- Authentication email handling stays scaffold-owned; customize only its React Email templates to retain verified dispatch behavior.
- App emails use the managed template helper in each existing feature function; only the existing administrator-composed HTML sender uses a direct managed API call because its free-form composition cannot fit fixed template props.
- Retain legacy email tables as audit-only records; never consult them to gate suppression or recreate email queues.
- Email event reactions stay in the scaffolded handle-email-events receiver and deduplicate audit writes using the event ID.
- Billing rules live in the shared billing policy; Checkout enforces trusted prices and Stripe trialing status grants annual access, so client input cannot override billing terms.
- Vault cloud operations are gated by verified annual entitlement in the shared plan-access predicate and hook; Lifetime keeps local storage only to prevent accidental cloud uploads.
- Local vault auto-unlock uses the restored auth session independently of subscription checks and cloud pulls, so offline access never grants cloud entitlement.
- Stripe subscription state is reconciled on account/vault refresh and before expiry actions without webhooks; trials must not produce paid receipts or annual-expiry reminders.
- Desktop packages are thin Electron shells (electron/main.cjs) loading the live site, packaged outside the project with @electron/packager, so web, auth and billing stay single-source.
